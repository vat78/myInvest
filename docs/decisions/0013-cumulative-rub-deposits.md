# ADR 0013: накопительные пополнения в RUB

Статус: принято. Дата: 2026-10-14.

На графике стоимости показывается отдельная линия суммы пополнений всех
портфелей на конец каждого дня. Для пополнения берётся сохранённый `amount`,
если валюта операции RUB, иначе `portfolio_amount`, если валюта портфеля RUB.
Курсы справочника не используются. Выводы, покупки, продажи, комиссии и сплиты
не меняют накопленную сумму пополнений. Будущие пополнения учитываются с их даты.

Миграция 0009 добавляет `daily_cash_balances.deposits_rub`: точную десятичную
строку TEXT накопленного итога портфеля. Go заполняет её при миграции и
перестраивает при записи журнала в той же транзакции, что остатки и оценки.
История до конца дня суммируется без округления; обзор переносит последний
снимок каждого портфеля и точно складывает суммы в Go. DTO передаёт строку,
интерфейс округляет только отображение до двух знаков. Чтение журнала при
открытии графика по-прежнему не требуется.

Текущая модель допускает старые пополнения без RUB в обеих валютах.
Если такая запись есть, `deposits_rub` равен NULL с её даты; линия получает
разрыв и объяснение. Подставлять ноль или вычислять рублёвую сумму по курсу
нельзя. После исправления записи либо её удаления полнота восстанавливается.
Полнота оценки стоимости и полнота пополнений независимы.

Сохранение дневного итога сохраняет архитектуру чтения обзора из снимков.
Агрегация журнала на каждом чтении повторяла бы работу записи; SQL SUM и REAL
нарушили бы контракт точности.
