# ADR 0003: точные ручные курсы валют

Статус: принято. Дата: 2026-10-12.

Обновление от 2026-10-13: сохранение одной записи и отсутствие вычислений
заменены [ADR 0005](0005-inverse-currency-rates.md): прямой курс остаётся точным,
обратный рассчитывается с явным округлением, обе пары сохраняются атомарно.

Для спецификации 001 курс — положительная десятичная строка без ограничения
числа дробных знаков. Go проверяет синтаксис без float и арифметики: удаляет
краевые пробелы, заменяет запятую точкой и лишние ведущие нули целой части.
Дробная часть, включая конечные нули, сохраняется. Знаки, экспонента,
разделители групп и пустые части числа запрещены. Округления нет.
Библиотека decimal пока не нужна: эта фича не вычисляет суммы или конвертации.
Для будущих вычислений потребуется отдельное решение.

SQLite хранит курс как TEXT в таблице currency_rates. Ключ — календарная дата
YYYY-MM-DD и упорядоченная пара кодов; обе валюты ссылаются на currencies.
Повторное сохранение — атомарный UPSERT одной записи. Добавление валюты —
отдельное явное действие, идемпотентное по нормализованному коду.
Начальная миграция добавляет RUB и USD, но не создаёт курсов.

Предметные проверки и сценарии находятся в internal/currency, интерфейс
хранения определяется этим модулем; `internal/currency/sqlite` его реализует.
`internal/currency/desktop` передаёт строковые DTO. UI получает локальную
календарную дату из системных часов,
проверяет её при возврате в окно и периодически, запрашивая именно курс этой
даты. Ответы устаревших запросов не заменяют данные текущей даты или пары.
Изменение разделителя при отображении — только форматирование строки.

Сгенерированные Wails JS-обёртки исключены из проверки исходников: генератор
не аннотирует параметры функций. Их контракт проверяется через генерируемые
`.d.ts` и `models.ts`; строгая проверка TypeScript/Svelte приложения сохраняется.
