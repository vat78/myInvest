# ADR 0012: сохранённая дневная оценка и главный экран

Статус: принято. Дата: 2026-10-14.

## Решение

Запрос на реализацию фичи 007 утверждает её уточнения. Обзор читает только
согласованный снимок дневных остатков, справочника и курсов, без чтения журнала.
В daily_asset_balances миграция 0008 добавляет стоимость позиции в валюте
портфеля: точные числитель и положительный знаменатель TEXT, а также ID сделки,
задавшей цену. NULL в обоих полях означает отсутствие оценки; ноль — 0/1.
Цена — сохранённая средняя цена последней покупки или продажи в этом портфеле
(18 знаков half up по ADR 0008). Последующие split меняют цену обратно
пропорционально количеству. Расходы учитываются только в денежном остатке.

Количество и стоимость строятся вместе в Go при записи истории в одной
транзакции. Миграция заполняет оценки тем же пересчётом; прежние миграции
и их схемы поддерживаются неизменными. Журнал остаётся источником истины
для восстановления производных данных. Дни без операций переносят снимок.

Рациональное хранение сохраняет стоимость без округления промежуточной
оценочной цены, которая после split может быть периодической.
Суммирование и конвертация в RUB выполняются точно в Go. Только итоговые DTO
сумм округляются half up до 18 знаков (для отрицательных — от нуля при половине),
проценты — до двух. Доли считаются из точных сумм до округления.
Последний прямой курс не позднее даты применяется без кросс-конвертации.
Курс и тип не меняют сохранённую стоимость в валюте портфеля.

Будущие точки не входят в обзор до наступления даты. Неполные оценки дают
разрывы графика; отрицательные составляющие заменяют круговую диаграмму
таблицей с предупреждением. Тип без классификации имеет отдельную группу.

## Альтернативы и последствия

Чтение журнала при открытии экрана повторяет работу записи и исключено.
Одна округлённая стоимость TEXT теряет точность при последующем суммировании;
два целых TEXT сохраняют её, включая результаты обратных сплитов.
Отдельная таблица итогов портфеля дублирует данные и пока не нужна.
Обзор требует только дневных снимков; изменения истории атомарно обновляют их.
