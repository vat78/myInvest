# ADR 0018: независимые исторические ряды бенчмарков

Статус: принято. Дата: 2026-10-14.

## Контекст и решение

Бенчмарки не являются торгуемыми активами и не принадлежат портфелю.
Модуль `internal/benchmarks` отделяет предметные расчёты и сценарии от адаптеров
SQLite/Wails. Миграция 0012 создаёт справочник и историю с ключом (benchmark_id,date).
Опциональная валюта с внешним ключом отличает денежную стоимость от индекса.

Финансовые поля — TEXT и строковые DTO. `math/big.Rat` выполняет точную арифметику.
Умножение конечных десятичных значений даёт конечную десятичную стоимость без
округления. Деление для производного прироста округляется half away from zero
до 18 знаков. Первая стоимость положительна, прирост больше −100%, поэтому
база сравнения всегда положительна. Первый прирост — NULL, в DTO пустая строка.

Исходные mode/input сохраняются вместе с value/growth. Хранить только
стоимость и процент недостаточно: после редактирования прошлого неизвестно,
какие значения пользователь хотел фиксировать. Поэтому пересчёт сохраняет
введённые стоимости и проценты согласно исходному способу. Сценарий сортирует
историю и вызывает предметный расчёт; репозиторий начинает транзакцию и получает
блокировку записи перед чтением. Все изменения цепочки фиксируются или откатываются
вместе. SQL и транзакции не выходят из адаптера хранения. Предварительный расчёт
не записывает данные; сохранение повторяет расчёт по актуальному снимку.

## Последствия

Ручные ряды универсальны: индекс инфляции, накопленный депозит или цена недвижимости.
Годовая ставка не интерпретируется автоматически как доход за период.
Сохранение пересчитывает весь выбранный ряд за O(n); для ручного ввода это позволяет
просто гарантировать согласованную историю. Новые зависимости не требуются.
Графики и сравнение с портфелями требуют отдельной спецификации.
