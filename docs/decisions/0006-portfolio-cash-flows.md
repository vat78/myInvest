# ADR 0006: точные денежные операции

Статус: принято. Дата: 2026-10-13.

Суммы нормализуются в десятичные строки без округления. Арифметика в Go
использует math/big.Rat и math/big.Int: знаменатель сумм содержит только
степени 2 и 5, поэтому остаток форматируется в конечную десятичную дробь
без потери точности. Новая библиотека не требуется. SQLite хранит суммы TEXT;
остаток не хранится и вычисляется из снимка журнала, без SQL-агрегаций.

Справочный курс — отношение фактической суммы в валюте портфеля к исходной.
Он округляется один раз до 4 дробных знаков, half up. Конечные нули
удаляются. Очень малый курс может отображаться как 0; UI явно обозначает
округление. Для одной валюты курс равен 1. Курс не восстанавливает суммы.

По согласованию с пользователем отрицательный остаток разрешён с
предупреждением. Будущие даты и даты до открытия портфеля разрешены;
проверяется только корректность календарной даты. Дата открытия портфеля
может редактироваться независимо от истории.

Проверки портфеля, валюты и существующей операции и запись выполняются
в одной транзакции. Редактирование и удаление ограничены идентификатором
портфеля; перенос записи между портфелями исключён. Чтение истории и валюты
использует одну транзакцию. Внешние справочные курсы не читаются и не меняются.
