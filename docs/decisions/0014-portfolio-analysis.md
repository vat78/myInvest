# ADR 0014: анализ по покупкам портфеля

Статус: принято. Дата: 2026-10-14.

## Решение

Фича 008 реализуется в модуле valuation отдельным сценарием анализа.
В отличие от обзора 007 с ценой последней сделки, анализ использует только
покупки и среднюю цену всех покупок. Пользователь подтвердил исключение
расходов и денег из долей и приведение купленных единиц при split.

Адаптер operations/sqlite читает валюту и историю выбранного портфеля
до даты включительно в одной read-only транзакции. Повторно используется
проверка полноты деталей операций. valuation/sqlite адаптирует этот снимок.
Расчёт в Go за один проход упорядоченных событий накапливает остаток,
купленные единицы, сумму покупок и последнюю цену покупки с поправкой split.
Средняя цена остаётся рациональной до умножения; суммы и цены DTO округляются
half up до двух знаков, количество сохраняется точно. Для геометрии диаграммы
передаётся доля из точных стоимостей с 18 знаками (нормализация исключает
переполнение суммы координат); при потере ненулевой доли диаграмма
не рисуется. Подписи всегда берутся из строковых значений Go.

## Альтернативы и последствия

Дневные снимки 007 не содержат историю покупок и используют также продажи;
они не подходят для требуемых формул. Чтение журнала анализа не меняет
контракт обзора, который по-прежнему читает только сохранённые дневные итоги.
Отдельное хранение аналитических агрегатов потребовало бы миграции и ещё
одного пересчёта при CRUD; пока оно не нужно. Сложность расчёта O(n log n)
для порядка и O(n) для прохода; память O(n + число активов).
