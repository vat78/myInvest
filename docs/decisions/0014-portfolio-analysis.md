# ADR 0014: анализ портфеля и себестоимость FIFO

Статус: принято. Дата: 2026-10-14. Обновлено: 2026-10-15.

## Решение

Фича 008 реализуется в модуле valuation отдельным сценарием анализа.
Текущая стоимость определяется по ADR 0016, себестоимость остатка — по FIFO.
Пользователь подтвердил FIFO вместо прежних формул средней по всем покупкам
и разности сумм покупок и продаж. Комиссии и дивиденды исключены.

Адаптер operations/sqlite читает валюту и историю выбранного портфеля
до даты включительно в одной read-only транзакции. Повторно используется
проверка полноты деталей операций. valuation/sqlite адаптирует этот снимок.
Расчёт в Go сортирует события по дате, split первым, затем по числовому ID.
Для каждого актива поддерживаются текущий остаток и очередь партий покупок.
Партия содержит точные количество и сумму приобретения в math/big.Rat.
Продажа списывает начало очереди, включая пропорциональную часть партии;
выручка не участвует в себестоимости остатка. Полностью списанные партии удаляются.
При split количества оставшихся партий меняются пропорционально new/old,
суммы приобретения сохраняются. Даже при рациональном количестве отдельной
партии общий остаток проверяется прежним правилом SplitQuantity.

Средняя себестоимость = себестоимость остатка / текущее количество,
при нулевом количестве оба значения равны нулю. Закрытые позиции скрыты.
Продажа сверх имеющихся партий отмечает FIFO этого актива как недоступный
до исправления истории; поздние покупки не восстанавливают неизвестные партии.
Рыночная оценка при этом доступна по прежним правилам; операции не запрещаются.
Целевое распределение использует общий проход только для остатков и источника
цены и не строит очередь FIFO.

Суммы и цены DTO округляются half up до двух знаков, количество сохраняется
точно. Себестоимость остатка не восстанавливается из округлённой средней.
Для геометрии диаграммы передаётся доля из точных рыночных стоимостей
с 18 знаками; при потере ненулевой доли диаграмма не рисуется.
Подписи берутся из строковых значений Go.

## Альтернативы и последствия

Средняя по всем покупкам сохраняет в расчёте проданные партии. Разность
сумм покупок и продаж зависит от реализованного результата. FIFO показывает
себестоимость именно оставшихся партий согласно согласованному порядку списания.
Дневные снимки не содержат партий; анализ читает журнал, обзор продолжает
читать дневные снимки. Изменение не требует миграций и новых зависимостей.

Сортировка занимает O(n log n); проход по сделкам — O(n), так как каждая
партия создаётся и полностью списывается не более одного раза. Каждый split
дополнительно проходит по оставшимся партиям своего актива. Память — O(n).
