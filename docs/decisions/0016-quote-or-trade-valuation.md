# ADR 0016: оценка по последней котировке или сделке

Статус: принято. Дата: 2026-10-14.

## Решение

Запрос пользователя заменяет источник текущей стоимости на всех экранах:
обзор, график истории, карточки, анализ и диаграммы. На дату D выбирается
последняя котировка актива или последняя покупка/продажа этого портфеля,
чья исходная дата не позднее D. Более поздняя дата побеждает; одинаковая дата
отдаёт приоритет котировке (цена на конец дня). Из сделок одной даты берётся
наибольший ID. Сделка другого портфеля не участвует. Котировка общая.
Из котировок одной даты предпочтительна валюта портфеля, иначе первый код
валюты в лексикографическом порядке. Это воспроизводимое разрешение неоднозначности
нескольких ручных цен. Доступность курса не подменяет выбор более ранним источником.

Цена котировки корректируется на split этого портфеля с датами строго после
даты котировки и не позднее D: множитель old/new. Split в дату котировки уже
входит в единицы цены на конец дня. Цена сделки берётся с сохранённым округлением
ADR 0008 и поправками split. Сплит не изменяет исходную дату источника цены.
Котировка другой валюты переводится по последнему прямому курсу
«валюта котировки → валюта портфеля» не позднее D. Кросс-курсов и неявного
использования будущих курсов нет. При отсутствии нужного курса оценка неполная,
исторический график имеет разрыв. Нулевой позиции цена и курс не нужны.

Общий индекс в valuation сортирует котировки, курсы и накопительные коэффициенты
split один раз; поиск по дате — бинарный. Точные цены котировок и курсы
разбираются в рациональные числа при подготовке индекса. История кеширует
готовые дневные итоги между датами изменения снимков, котировок, курсов и
split. Неполная оценка пересчитывается, чтобы сообщения сохраняли дату
конкретной точки. Кеш существует только в пределах одного построения обзора.
Все значения и промежуточные
вычисления точные math/big.Rat. DTO округляются по существующим правилам.
Средняя цена всех покупок и стоимость по ней не заменяются котировками.

## Хранение и последствия

Схема не меняется. Сохранённые дневные количества и стоимости по сделкам
остаются источником для обзора; котировки накладываются при чтении и не
перезаписывают исторические сделки или остатки. Уточняется ADR 0012:
снимок обзора дополнительно читает дату источника по price_operation_id
и только сведения о split из журнала. Количества и цены сделок заново
из журнала не рассчитываются, таблица trade_details обзору не нужна.
Дневные суммы строятся для каждой даты с её котировками и курсами, включая
дни без операций. Анализ читает историю, котировки и курсы одной транзакцией.

Сохранение котировки немедленно обновляет обзор и анализ. Анализ показывает
источник цены, его дату, валюту и применённый валютный курс с датой.
Правило заменяет ограничения ADR 0014 и 0015 о неиспользовании котировок.
