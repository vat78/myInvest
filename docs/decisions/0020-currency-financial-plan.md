# ADR 0020: независимый финансовый план в выбранной валюте

Статус: принято по уточнениям пользователя. Дата: 2026-10-14.

План связан только с валютой из справочника, один сохранённый план на валюту.
Начальный капитал всегда задаётся вручную. Выбор портфеля и источника капитала,
зависимость от исторической оценки и чтение журнала удалены из планирования.
Расчёты, точность, годовые границы, округление и исходный снимок сохраняют
правила ADR 0019.

В выборе покупательной способности доступны все бенчмарки независимо от наличия
валюты. Метаданные валюты не позволяют определить назначение ряда: пользователь
сам выбирает подходящий индекс. Отношение стоимости на двух границах года
безразмерно; валютная конвертация ряда не нужна. Прежний фильтр скрывал
существующие ряды с валютой в UI, а API дополнительно отклонял их.

Миграция 0014 создаёт STRICT-таблицу currency_financial_plans с ключом/FK
currency_code. Сохранение параметров и исходного снимка атомарно. Версия
защищает от устаревших записей. Финансовые значения остаются TEXT.
Миграция 0013 не изменяется: она могла уже примениться в пользовательской БД.
Прежние строки financial_plans сохраняются полностью, включая исходные снимки.
Если для валюты существует ровно один прежний план, он копируется с прежней
версией, точным начальным капиталом и исходным сценарием. При нескольких планах
одной валюты автоматического выбора нет: прежние данные остаются в legacy-таблице,
новый план пользователь задаёт самостоятельно. Прежний капитал становится
фиксированным параметром; при следующем сохранении используется ручное значение
формы. Новые планы не требуют существования ни одного портфеля.
