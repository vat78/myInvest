# ADR 0022: сравнение рублёвой доходности через TWR

Дата: 2026-10-16. Статус: принято для реализации.

Сравнение расширяет internal/valuation и использует прежние правила оценки
котировок/сделок ADR 0016. Отдельный ComparisonService читает дневные снимки,
внешние денежные потоки и бенчмарки в одной read-only транзакции. Обзор
продолжает читать прежний снимок без денежных потоков и бенчмарков.
Миграция и новые библиотеки не требуются.

Выбран TWR с потоками на конец дня: изменение стоимости не подходит из-за
пополнений, прибыль/взносы зависит от структуры потоков, XIRR измеряет другой
результат — доходность вложенного капитала с учётом времени внесения.
Ограничение дневной модели явно указано в интерфейсе. Между потоками
коэффициенты телескопируются, поэтому достаточно оценок в даты потоков,
годовых границ и начала, без ежедневного обхода истории.

Начальную привязку задаёт явно выбранный пользователем индекс инфляции.
Название ряда не используется как скрытый признак. Старт позднего портфеля
привязан к последнему доступному значению инфляции на дату формирования,
без интерполяции. График показывает накопленный результат, таблица дополнительно
показывает годовой: это сохраняет смысл начальной нормировки.
Правила и примеры — в спецификации 014.
