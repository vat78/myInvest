# ADR 0021: дивиденды в валюте портфеля

Статус: принято. Дата: 2026-10-14.

По запросу пользователя добавлен вид операции `dividend` с необязательным
активом и суммой исключительно в валюте портфеля. Сумма означает фактическое
зачисление после удержаний. Отдельные налоги и комиссии не вычисляются.

Миграция 0015 расширяет CHECK общего журнала и добавляет `dividend_details`:
`operation_id` — PK/FK с каскадным удалением, `asset_id` — nullable FK,
`amount` — положительная точная десятичная строка TEXT. Пустой ID адаптер
сохраняет как NULL. Отдельная валюта не хранится: валюта портфеля неизменна.
Триггеры защищают принадлежность деталей и неизменность семейства операций.

Расширение CHECK выполняется атомарным пересозданием журнала и его деталей
по схеме миграции 0006, с сохранением ID, сплитов и sqlite_sequence.
Удаление прежней таблицы сбрасывает ссылки дневных цен через ON DELETE SET NULL;
Go-шаг 0015 в той же транзакции заново строит все производные дневные снимки.
Резервная копия существующей БД обеспечивается штатным runner миграций.
Предыдущие миграции и их прежние схемы чтения сохраняются.

Go использует math/big: выплата увеличивает деньги, не меняя количества,
цен и пополнений. DTO содержит строки; отдельный SaveDividend не принимает
валюту или сумму конвертации. UI не выполняет финансовых расчётов.
