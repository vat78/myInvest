# ADR 0002: переносимое хранилище

Статус: принято. Дата: 2026-10-12.

## Контекст

Нужен режим хранения БД рядом с приложением. Системный каталог из ADR 0001
остаётся подходящим для обычной установки, где каталог бинарника может быть
недоступен для записи. На macOS замена `.app` не должна удалять переносимую БД.

## Решение

`MYINVEST_DATA_DIR` сохраняет высший приоритет. Без него `MYINVEST_PORTABLE=1`
выбирает переносимый каталог; отсутствие переменной или `0` сохраняет прежнее
поведение. Иные значения вызывают ошибку запуска.

Путь определяется через `os.Executable()` и `filepath.EvalSymlinks()`, независимо
от cwd. Для macOS-бинарника в `<имя>.app/Contents/MacOS` используется родитель
`.app`. В остальных случаях используется каталог бинарника. Имя файла остаётся
`myinvest.sqlite3`; WAL и `backups/` остаются рядом с ним. URI SQLite с буквой
Windows-диска содержит ведущий `/`, чтобы диск не трактовался как authority.

## Последствия

Переключение режима не переносит существующие данные. Пользователь выбирает
каталог явно; при ошибке доступа приложение завершает запуск, без автоматического
перехода в другой каталог. Символическая ссылка не меняет расположение данных.
В разработке переносимый путь зависит от размещения сгенерированного бинарника.
Несколько приложений в одном переносимом каталоге используют одну БД.
Изменения схемы и новые зависимости не требуются.
